# VLC Control — виджет Xbox Game Bar

Виджет для Game Bar (`Win+G`), который управляет локальным VLC через его HTTP-интерфейс: скорость, перемотка, пауза, громкость, плейлист и название текущего файла — не выходя из игры.

![Виджет в Game Bar](docs/gamebar-vlc2.png)

## Возможности

- Название текущего трека и состояние (`Играет` / `Пауза`)
- Прогресс-бар: клик или перетаскивание для перемотки, счётчики текущего времени и длительности
- Перемотка ±10 секунд, предыдущий/следующий файл, пауза
- Громкость: слайдер + быстрый mute (восстанавливает прежний уровень)
- Скорость: 0.5×, 0.75×, 1×, 1.25×, 1.5×, 2×
- Плейлист VLC с переходом на любой файл по клику
- Настройки подключения прямо в виджете: хост, порт, пароль, кнопка проверки связи

Виджет ничего не эмулирует и не ищет окна: он общается с VLC по документированному web-интерфейсу (`status.xml`, `playlist.xml`), поэтому работает и с VLC в фоне, и с полноэкранными играми.

## Требования

- Windows 10 версии 1903+ или Windows 11
- Xbox Game Bar (входит в Windows, `Win+G`)
- VLC 3.x
- Для установки из исходников/архива — включённый **режим разработчика** (`Параметры → Система → Для разработчиков`) и [Visual Studio 2022](https://visualstudio.microsoft.com/) с рабочей нагрузкой «Разработка приложений для универсальной платформы Windows» + Windows SDK 10.0.22621

## Установка

### 1. Включить HTTP-интерфейс VLC

Закрой VLC и запусти:

```powershell
powershell -ExecutionPolicy Bypass -File tools\setup-vlc.ps1
```

Скрипт делает бэкап `%APPDATA%\vlc\vlcrc` и прописывает:

```ini
extraintf=http
http-host=127.0.0.1
http-port=8080
http-password=gamebar
```

Вручную то же самое: `Инструменты → Настройки → Все → Интерфейс → Основные интерфейсы → Web`, затем `Lua → HTTP` (пароль, порт).

Проверка: запусти VLC и открой `http://127.0.0.1:8080/requests/status.xml` (логин пустой, пароль `gamebar`).

### 2. Собрать

```powershell
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

> Сборка **всегда** начинается с удаления `obj` и `bin`. Инкрементальная сборка .NET Native периодически оставляет битые артефакты — пакет после этого регистрируется, но молча не запускается (ошибка `TWinUI 5961`, «Приложение не запустилось»). Скрипт делает это за тебя.

### 3. Установить

```powershell
powershell -ExecutionPolicy Bypass -File tools\install.ps1
```

Скрипт снимает старую версию пакета, регистрирует свежую (`Add-AppxPackage -Register ...\ilc\AppxManifest.xml`), выдаёт loopback-исключение (без него UWP не достучится до `127.0.0.1`) и перезапускает Game Bar.

### 4. Добавить виджет

`Win+G` → иконка сетки виджетов → **VLC Control** → закрепить (📌), чтобы он оставался на экране.

## Использование

| Элемент | Действие |
| --- | --- |
| Прогресс-бар | клик/драг — перемотка |
| ⟲10 / 10⟳ | −10 / +10 секунд |
| ⏮ / ⏭ | предыдущий / следующий файл плейлиста |
| Кружок в центре | пауза / воспроизведение |
| Слайдер с динамиком | громкость, клик по динамику — mute/unmute |
| Чипы `0.5×…2×` | скорость воспроизведения |
| Иконка списка | показать/скрыть плейлист |
| Шестерёнка | настройки подключения |

Ограничения Game Bar: виджет виден только в оверлее, поверх эксклюзивного полноэкранного режима игры он не рисуется — используй «окно без рамки» или полноэкранный оптимизированный режим.

## Настройки

Шестерёнка → хост, порт, пароль → «Проверить» (показывает текущий файл из VLC) → «Сохранить». Настройки хранятся в `LocalSettings` пакета и переживают перезапуск.

Если VLC не отвечает, виджет показывает экран «VLC не отвечает» с кнопками «Повторить» и «Настройки».

## Решение проблем

| Симптом | Причина / решение |
| --- | --- |
| «Приложение не запустилось» при `Win+G` | Битая инкрементальная сборка .NET Native → `rm -rf obj bin` (на Windows: удалить папки) и пересобрать `tools\build.ps1` |
| Виджет пишет «Нет связи» | VLC не запущен; HTTP-интерфейс выключен; другой пароль/порт; не выдано loopback-исключение (`tools\install.ps1`) |
| Виджет не появился в меню Game Bar | Перезапустить Game Bar: `Stop-Process -Name GameBar,GameBarFTServer -Force; Start-Process ms-gamebar:` |
| Скорость/громкость не меняются | VLC не принимает команду для текущего кодека/файла; проверь вручную через `status.xml?command=rate&val=1.5` |
| Виджет пропал после переноса папки | Пакет зарегистрирован «loose» из `bin\x64\Release\ilc` — папку нельзя удалять/переносить, переустанови `tools\install.ps1` |

Логи: `%LOCALAPPDATA%\Packages\VlcGameBarWidget_11mkq6sn63zaj\LocalState\crash.log`.

## Структура проекта

```
src/VlcGameBarWidget/
  App.xaml(.cs)            точка входа, активация Game Bar-виджета
  Widget1.xaml(.cs)        интерфейс и вся логика управления
  VlcClient.cs             HTTP-клиент VLC (status.xml, playlist.xml, команды)
  Converters.cs            конвертеры кистей для выделения текущего пункта
  Package.appxmanifest     identity, расширение Game Bar, proxyStub/inproc server
tools/
  setup-vlc.ps1            настройка vlcrc (HTTP, пароль, порт)
  build.ps1                чистая Release-сборка .NET Native
  install.ps1              регистрация пакета + loopback + рестарт Game Bar
```

## Как это работает

`App.OnActivated` получает `XboxGameBarWidgetActivatedEventArgs` по протоколу `ms-gamebarwidget` и создаёт `XboxGameBarWidget`, который привязывает XAML-страницу к окну Game Bar. Страница раз в секунду опрашивает `status.xml`, обновляет заголовок, время, громкость и скорость, а действия пользователя превращаются в команды `pl_pause`, `pl_next`, `pl_previous`, `pl_play&id=N`, `seek&val=±10S`, `seek&val=…%`, `rate&val=`, `volume&val=` (0–512, где 256 = 100%).
