## Виджет пишет «Нет связи»

VLC либо не запущен, либо запущен без HTTP-интерфейса.

- Нажми **«Запустить VLC»** в виджете — он стартует VLC с нужными параметрами, а если VLC уже открыт без HTTP — перезапустит.
- Если не помогло, проверь адрес: хост `127.0.0.1`, порт `8080`, пароль `gamebar` (настройки виджета → шестерёнка).

## Виджет не появился в меню Game Bar

Перезапусти Game Bar:

```powershell
Stop-Process -Name GameBar,GameBarFTServer -Force -ErrorAction SilentlyContinue
Start-Process ms-gamebar:
```

Дальше `Win+G` → иконка сетки виджетов → **VLC Control**.

## Виджет не рисуется поверх игры в эксклюзивном полноэкранном режиме

Это ограничение Game Bar, а не ошибка: виджеты рисуются только в оверлее, но никогда поверх эксклюзивного полноэкранного режима. Используй «окно без рамки» или полноэкранный режим «оптимизированный».

## Панель не видит VLC

Открой шестерёнку и проверь настройки подключения: хост `127.0.0.1`, порт `8080`, пароль `gamebar`. Это те же значения, которые установщик пишет в `%APPDATA%\vlc\vlcrc`.

## Не меняются скорость или громкость

Некоторые кодеки не принимают команды `rate` / `volume` во время воспроизведения. Попробуй поставить на паузу или открыть другой файл.

## Установщик не смог зарегистрировать виджет

Для установки приложений вне магазина нужен режим разработчика:

**Параметры → Система → Для разработчиков**. Установщик включает его сам, если есть права администратора; если не смог — включи вручную и запусти установщик ещё раз.

## VLC не видит настройки, записанные установщиком

- Если во время установки VLC был запущен, его файл настроек намеренно не трогали. Закрой VLC и запусти снова — или повтори установку, закрыв VLC заранее.
- Установщик всегда сохраняет рядом с оригиналом резервную копию с меткой времени: `%APPDATA%\vlc\vlcrc.backup-YYYYMMDD-HHMMSS`.

## Где лежат логи

| Лог | Путь |
| --- | --- |
| Установщик | `%APPDATA%\VlcControl\setup.log` |
| Деинсталлятор | `%APPDATA%\VlcControl\uninstall.log` |
| Падение установщика | `%APPDATA%\VlcControl\setup-error.log` |
| Падение виджета | `%LOCALAPPDATA%\Packages\VlcGameBarWidget_11mkq6sn63zaj\LocalState\crash.log` |

## Начать заново

Удали **VLC Control** из *Параметры → Приложения*, затем на всякий случай удали `%LOCALAPPDATA%\Programs\VLCControl` и `%APPDATA%\VlcControl` и запусти установщик заново.
